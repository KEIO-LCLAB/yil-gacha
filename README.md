# YIL COLLECTION GACHA

慶應義塾大学・矢上祭のYIL展示向け静的ガチャアプリ。外部ライブラリ不要。個人情報は収集しません。

公開サイト: https://keio-lclab.github.io/yil-gacha/
管理者ページ: https://keio-lclab.github.io/yil-gacha/admin.html

## 遊び方

カード枚数を選び、ボタンまたはハンドルで抽選。出てきたカプセルをタップして開封します。景品はシールかクリアファイルのいずれかです。クリアファイルからシールへの変更は可能、逆は不可です。「もう一度」で次の参加者へリセットします。

## 上限設定

- 共通設定: settings.jsonのmaxCardsを2〜11にしてGitHubへコミット。自動公開が成功した後、全端末に反映されます。初期値11。
- 端末別設定: 運営用ページを開いて保存。このブラウザのlocalStorageに保存され、共通設定より優先します。同じ端末でもブラウザが違うと別設定です。
- 「共通設定に戻す」で端末別設定を解除できます。
- 開始時・30秒ごと・画面復帰時・抽選直前に設定を確認します。抽選中の変更は次の参加者へ反映します。
- 共通設定の読み込みに失敗した場合は抽選を停止します。端末別設定がある場合は通信不要で設定を取得できます。

運営用ページにはパスワードを設けず、通常画面からのリンクを外しています。URLを知る人は利用できますが、変更対象はそのブラウザのみです。全端末の設定変更はGitHubの書き込み権限で保護されます。

## 確率

クリアファイル確率（%） = round(100 × ((枚数 − 1) / (上限 − 1)) ^ 1.7)。シールは残りの確率。1枚0%、上限100%。10個のカプセルの色の割合も同じ確率に連動します。抽選はMath.random()で一度だけ行います。

上限11枚の場合:

|枚数|クリアファイル|シール|
|---|---|---|
|1|0%|100%|
|2|2%|98%|
|3|6%|94%|
|4|13%|87%|
|5|21%|79%|
|6|31%|69%|
|7|42%|58%|
|8|55%|45%|
|9|68%|32%|
|10|84%|16%|
|11|100%|0%|

## 起動・公開

index.htmlを直接ブラウザで開けます。file://では共通設定を11枚として動作し、端末別保存の可否はブラウザに依存します。ローカルHTTPでは `python3 -m http.server 8000` で起動し、localhost:8000を開きます。

mainへのpushでGitHub Actionsがテスト・ビルド・GitHub Pages公開を実行します。`node build.cjs` は公開ファイルだけをpublic/に生成します。Firebaseへの依存はありません。

`node tests/probability.test.cjs` と `node tests/settings.test.cjs` で検証します。URLの ?debug=1 で確率と抽選状態を確認できます。音は操作後に鳴ります。prefers-reduced-motionを尊重します。
